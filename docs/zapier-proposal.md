# Week 8 proposal: Zapier as Dev Squad’s messenger

**Problem.** Moving reports and writing the next agent prompt by hand interrupts the owner and can lose context. Measured time per manual handoff is **[PLACEHOLDER] minutes**; current jobs per week are **[PLACEHOLDER]**. These have not been measured by this implementation.

**Solution.** After each approved worker step, Dev Squad sends a cleaned summary to a Zapier Catch Hook. An AI step drafts the next prompt; GitHub stores it on the private repository’s separate `handoffs` branch. Dev Squad accepts only the expected job, completed round and next role. Default pilot: **3 agent rounds**, at most **3 reports and 2 between-agent prompt pickups**, with a **5-minute maximum wait** per pickup. Stop, independent review, paid-request controls and final owner acceptance remain in force.

**Cost.** Local mock tests use **$0 in external API/Zapier usage**. The published multi-step Webhooks → AI → GitHub workflow needs a qualifying Zapier paid plan or active trial; the advertised Professional starting price is **$19.99/month**, with billing term, included tasks, tax and overages to be confirmed in the owner’s account. Budget **up to 9 successful action tasks** for three rounds at Standard AI tier: AI + GitHub file read + GitHub file write, three times. This is a planning estimate, not an account quote.
